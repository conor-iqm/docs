An ICT audience is created as a group: the audience built from the uploaded file (the parent audience) and one extension audience per requested [extension subtype](#ict-audience-subtypes-and-extensions). The group is identified by the parent audience ID (<var>parentId</var>) and named after the audience name given at creation.

### ICT audience group list

<CopyUrl method="POST" url="https://api.iqm.com/api/v3/audience/ict/list" operationId="getICTAudienceGroupList" />

<div class="endpoint-container">

Get a list of ICT audience groups, with the audiences of each group nested under it.

* Pagination and sorting apply to the groups, not to the audiences within a group.
* Filters apply to the audiences: a group is returned only if at least one of its audiences matches, and only the matching audiences are listed under it.
