# Finance API

This page covers the methods and endpoints associated with finance operations. With the Finance API you can access and manage VLD Insights report fees. 

<div class="definitionsTable">
  | Type | Vertical |
  | --- | --- |
  | **Voter Level Data (VLD) Insights** | Political vertical
  | **Provider Level Data (PLD) Insights** | Healthcare vertical
  | **Script Lift Study (SLS) Insights** | Healthcare vertical
  | **AQ Insights Report** | Healthcare vertical
  | **Integrated Care Team (ICT) Insights** | Healthcare vertical
  | **Nurse Level Data (NLD) Insights** | Both Political and Healthcare verticals
</div>

Use the following header parameters for all requests:

| `X-IAA-OW-ID` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | Organization Workspace ID Header |
