# Asset API

The Asset API stores and manages files in two ways:

* **Assets** are files for creatives, such as images, PDF files, and HTML5 creative assets (ZIP files), served from a CDN URL. The Asset API handles media uploads and temporary storage, and works with other services, such as the Creative API, for final storage and metadata management.
* **Secure files** are kept in private storage and shared through presigned URLs that expire. They have no CDN URL. Each secure file belongs to the Organization Workspace that uploaded it, and only users in that Workspace can access it.

To upload a secure file:

1. [Initiate secure file upload](#initiate-secure-file-upload) to get a <var>fileId</var> and a presigned <var>uploadUrl</var>.
2. Send the file to <var>uploadUrl</var> in a `PUT` request before the URL expires. Set the `Content-Type` header to the file type's content type and send exactly the number of bytes given in <var>size</var>. Don't send IQM authentication headers to this URL.
3. [Complete secure file upload](#complete-secure-file-upload) to confirm the file is uploaded.

After that, you can [get a download URL](#get-secure-file-download-url) for the file.

This page covers the common endpoints and methods associated with the Asset API.

<div class="endpoint-container">
<div class="child1">

| Request schema | |
| --- | --- |
| `fileName` <br /><span class="type-text">string</span> <span class="required-text">required</span> | File name, including the extension. The extension must match <var>fileType</var>. Spaces are replaced with underscores, and characters other than letters, numbers, `.`, `_`, and `-` are removed. |

| `size` <br /><span class="type-text">integer</span> <span class="required-text">required</span> | File size in bytes, up to <var>524288000</var> (500 MB). The uploaded file must be exactly this size. |
| `folderName` <br /><span class="type-text">string</span> | Folder to group the file under in storage. Letters, numbers, `_`, and `-` only, up to 100 characters. |

| `fileType` | Extensions | `Content-Type` for the upload |

| <var>CSV</var> | `.csv` | `text/csv` |
| <var>EXCEL</var> | `.xlsx`, `.xls` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` (`.xlsx`) or `application/vnd.ms-excel` (`.xls`) |

| <var>KMZ</var> | `.kmz` | `application/vnd.google-earth.kmz` |
| <var>KML</var> | `.kml` | `application/vnd.google-earth.kml+xml` |
| <var>PDF</var> | `.pdf` | `application/pdf` |
| <var>DOC</var> | `.doc` | `application/msword` |
| <var>DOCX</var> | `.docx` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| <var>TXT</var> | `.txt` | `text/plain` |
| <var>MD</var> | `.md` | `text/markdown` |
