# MCP Political Planner tutorial

Use IQM Model Context Protocol (MCP) to interact with the Political Planner in the Planner API.

## Overview

This tutorial guides you through using IQM MCP to create a Political plan, compare its strategies, activate a proposal, and generate an insertion order (IO) and draft campaigns. It also covers Voter TV+ plans, which forecast reach across linear TV and connected TV (CTV).

The Planner MCP supports a limited set of features of the Planner API. For a comprehensive list of supported features and best practices for using the Political Planner, refer to the [Political Planner](/political-vertical/tutorials/create-a-political-proposal) tutorial and the [Planner API](/political-vertical/planner) guidelines.

## Before you begin

To create a Political proposal and generate an IO, the following are required:

1. An account on the IQM platform
   * See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
1. IQM MCP connected to your AI assistant
   * See [MCP getting started](/mcp/mcp-getting-started)
1. Access to a Political Workspace
   * Political Planner requests from a Workspace outside the Political vertical are rejected
1. A Political Advertiser profile
   * Required to generate an IO. See [Get list of Advertiser profile and details](/guidelines/workspace-api#get-list-of-advertiser-profile-and-details)

## About the Political Planner

The Political Planner builds a forecast-backed media plan for a political campaign. A proposal goes through these steps:

**Create plan → Compare strategies → Activate proposal → Generate IO and campaigns**

Voter TV+ plans start from a reach saturation graph instead, and are activated without a strategy:

**Get reach graph → Create plan → Activate proposal → Split (optional) → Generate IO and campaigns**

## Voter TV+ proposals

Voter TV+ (objective <var>3</var>) plans forecast reach across linear TV and CTV. A Voter TV+ plan must have a flight of 7 to 31 days and a budget of at least <var>100</var>, and can't target Power Segment audiences.
