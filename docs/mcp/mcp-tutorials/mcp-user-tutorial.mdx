# MCP user tutorial

Use IQM Model Context Protocol (MCP) to interact with the User Management API. 

## Overview

This page provides instructions on using IQM MCP to perform operations related to user management, such as logging in and out, resetting or updating passwords, and updating user details such as profile information and status. 

## Before you begin

To access User Management API tools using IQM MCP, the following are required:

1. An account on the IQM platform
   *  See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
