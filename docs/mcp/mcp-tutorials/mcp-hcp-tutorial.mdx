# MCP Healthcare Professional (HCP) Planner tutorial

Use IQM Model Context Protocol (MCP) to interact with the HCP Planner in the Planner API.

## Overview

This tutorial guides you through using IQM MCP to generate, save, edit, publish, and download an HCP plan with the Planner API. Publishing a plan creates an insertion order (IO) and draft campaigns.

The Planner MCP supports a limited set of features of the Planner API. For a comprehensive list of supported features and best practices for using the HCP Planner, refer to the [Healthcare Professional (HCP) Planner](/healthcare-vertical/tutorials/create-an-hcp-proposal) tutorial and the [Planner API](/healthcare-vertical/planner) guidelines.

## Before you begin

To create and publish an HCP plan, the following are required:

1. An account on the IQM platform
   * See [Before you begin](/getting-started/before-you-begin) to create an account and request a Client ID and Client Secret
1. IQM MCP connected to your AI assistant
   * See [MCP getting started](/mcp/mcp-getting-started)
1. Access to a Healthcare Advertiser Organization
   * HCP Planner requests only work in the Healthcare vertical, and only Advertiser Organizations can publish plans

## About the HCP Planner

The HCP Planner builds a media plan that targets healthcare professionals by National Provider Identifier (NPI) type, specialty, location, and data partner. A plan goes through these steps:

**Generate campaigns → Save plan → Edit (optional) → Publish IO and campaigns**
